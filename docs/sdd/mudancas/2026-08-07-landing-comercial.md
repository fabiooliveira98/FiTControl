# Landing comercial do FitControl

## Motivo

A pagina publica apresentava termos internos como MVP, fases, SDD, stack e entregas tecnicas. Esse conteudo explicava o projeto, mas nao comunicava o valor do produto para uma potencial cliente.

## Impacto no produto

- nova narrativa centrada no problema de organizar cancelamentos e reposicoes
- previa visual da agenda para demonstrar a experiencia sem exigir login
- beneficios de uso no celular, semana e grupos apresentados com clareza
- chamadas direcionadas ao acesso do FitControl
- login com formulario imediato no mobile e contexto comercial no desktop

## Impacto tecnico

- componentes publicos organizados em `src/components/marketing`
- animacoes CSS com suporte a movimento reduzido
- metadata publica atualizada
- contraste do token `on-action` corrigido

## Arquivos SDD atualizados

- `01-visao-produto.md`
- `05-ui-design-system.md`
- `07-estado-atual.md`

## Status

Implementado e validado visualmente em mobile e desktop em 07/08/2026.
